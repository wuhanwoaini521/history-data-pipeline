# REGIME_STRUCTURE_REVIEW

> 多政权阶段（三国 / 东晋·十六国 / 南北朝）Regime 结构审查。
> 回答：哪些 Regime 并存？哪些是继承关系？哪些是并行关系？
> 是否错误地把并行 Regime 排成 Dynasty Chain？Period 是否错误等同于 Regime？

## 0. 结论

- `Period != Regime` 已在数据层落地：Period 是浏览/时间组织单位（31 个），
  Regime 是实际政权（31 → **42** 个），Event 同时携带 `period_id`（浏览归属）与
  `regime_ids`（参政政权，多政权事件并列记录）。
- **未**把并行政权排成串行 Dynasty 时间轴：东魏/西魏、北齐/北周、南朝四朝通过
  `parent_regime_id`（继承）与 Event `regime_ids`（并存/交互）双重表达。
- 十六国未"全收录"：仅维护支撑主线叙事的 7 个政权（前赵/后赵/前燕/前秦/后秦/后燕/北凉），
  合计 42 个 Regime。

## 1. 三国（period-three-kingdoms，220—280）

| Regime | 年代 | parent | 说明 |
|---|---|---|---|

- **并行关系**：三者同属 period-three-kingdoms，时间上有重叠（220—263 三足并存），
  绝非串行。夷陵之战（蜀×吴）、魏灭蜀（魏×蜀）等事件 regime_ids 并列双政权。
- 已有 3 个 Regime 未改动（复用 Batch2 前结构），新增 0。

## 2. 东晋 / 十六国（period-eastern-jin + period-sixteen-kingdoms，304—439）

| 后赵 | 319—351 | 北（羯） |

| 后秦 | 384—417 | 北（羌） |
| 北凉 | 397—439 | 北（卢水胡） |

- **并存关系**（交错时段）：东晋 ∥ 诸十六国；北方内部 前赵/后赵→冉魏→前燕→前秦→后燕/后秦 相继更替
  但时有并存（如前秦（351—394）与后燕/后秦（384 起）在 384—394 重叠）。
- 关键并存事件以 regime_ids 表达：淝水之战 = 东晋 + 前秦；北魏灭后燕 = 北魏 + 后燕；
  北魏统一北方 = 北魏 + 北凉。
- Period 归属：东晋历史事件归 period-eastern-jin；北方政权事件归 period-sixteen-kingdoms；
  **同一个政权（北魏 386—534）** 跨两个 Period（386—439 十六国段 / 439—534 南北朝段），
  以事件期而非政权期机械对应——这正是 Period(浏览) ≠ Regime(实体) 的体现。

## 4. 检查项清单

| 检查 | 结果 |
|---|---|
| 并存 Regime 是否被错误串行 | 否（东魏/西魏、北齐/北周、南朝四朝均并行，时间重叠） |
| 继承关系是否显式表达 | 是（parent_regime_id：东魏/西魏→北魏；北齐→东魏；北周→西魏） |
| Period 是否错误等同于 Regime | 否（北魏跨两 Period；三国 3 Regime 同 1 Period；多政权并存事件 regime_ids 并列） |
| 十六国是否全收录 | 否（仅主线 7 政权；冉魏等短命政权以 Event 表达不立 Regime） |
| 是否新增平行 Review 体系 | 否（沿用 data/reviews/accepted/ 规范） |

## 5. 说明

- Regime 新增 11 个（前赵/后赵/前燕/前秦/后秦/后燕/北凉 + 刘宋/南齐/梁/陈），
  均为支撑主干叙事的必要政权；`schemas/`（Period/Regime/Event 模型）未改。
- Regime 行内 `period_id` 为其所属浏览 Period；父政权的 `parent_regime_id` 表达继承，
  二者语义独立。
