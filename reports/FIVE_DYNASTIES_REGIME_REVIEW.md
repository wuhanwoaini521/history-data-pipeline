## 1. 五代（中原五个政权）

| Regime | 年代 | 创建 | 都 |
|---|---|---|---|
| 后梁 | 907–923 | 朱温（朱全忠）废唐哀帝 | 汴州（开封） |
| 后唐 | 923–936 | 李存勖灭后梁 | 洛阳 |
| 后晋 | 936–947 | 石敬瑭借契丹灭后唐 | 汴州 |
| 后汉 | 947–951 | 刘知远（太原军阀） | 开封 |
| 后周 | 951–960 | 郭威受禅 | 开封 |

- 五者均为**中原王朝更替链**（先后继承、非并存），但**不是**用 parent_regime_id 表达——
  五代之间是正统更迭（沙陀系与汉系交替），本库以事件链
  （后梁→后唐→后晋→后汉→后周 各建立 Event 的 follows/leads_to）表达
  **政权转换时序**。

  均以 events 与 regimes 并列表达，未误建 parent 链。

## 3. 哪些 Regime 同期并存（代表性时段）

| 时段 | 并存政权（Regime） |
|---|---|
| 907（后梁初） | 后梁 ∥ 前蜀 ∥ 吴 ∥ 吴越 ∥ 楚 ∥ 闽…（＋契丹可汗国） |
| 936–947（后晋） | 后晋 ∥ 契丹（辽）∥ 南唐 ∥ 后蜀 ∥ 吴越… |
| 947–951（后汉） | 后汉 ∥ 契丹（辽）∥ 南唐 ∥ 后蜀… |
| 951–959（后周） | 后周 ∥ 北汉（附辽）∥ 南唐 ∥ 后蜀 ∥ 吴越… |

- 并存以事件的 `regime_ids` 并列表达：**契丹灭后晋** = 辽+后晋；
  **燕云十六州割让** = 后晋+辽；**后周征南唐** = 后周+南唐。

## 4. 辽如何与五代并行

- `regime-liao`（契丹/辽，916–1125，period_id=period-liao）存在于 taxonomy，
  与五代中原政权并行；本批事件：
  - `event-qidan-jianguo`（916 阿保机称帝建契丹，period-liao）；
  - `event-yan-yun-shiliuzhou`（936–938 割燕云，后晋×辽）；
  - `event-qidan-mie-houjin`（946–947 灭后晋＋改国号大辽，辽×后晋）。
- 辽参与五代政治（燕云割让、灭后晋）均以双政权 regime_ids 表达，
  不在"五代 Dynasty List"中被串行化。

## 5. 检查项清单

| 检查 | 结果 |
|---|---|
| 五代是哪五个 Regime | 后梁/后唐/后晋/后汉/后周（均存在，period_id=period-five-dynasties-ten-kingdoms） |
| 十国实际维护哪些 | 10 个（吴/南唐/吴越/楚/闽/前蜀/后蜀/南汉/荆南/北汉） |
| 哪些同期并存 | 五代中原政权 ∥ 南方十国 ∥ 契丹/辽（见上表） |
| 辽是否与五代并行 | 是（regime-liao 与事件双政权表达） |
| 是否错误用 parent_regime_id 表达并行 | 否——五代之间用事件链（政权转换），十国/辽为独立 Regime 并列；parent_regime_id 仅用于北魏分裂系（Batch3） |
| 继承与并行是否区分 | 是：政权更替（五代替换/吴→南唐）用事件关系；并存（十国/辽）用 regime_ids 并列 |
